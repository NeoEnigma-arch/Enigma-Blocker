# AMO Listing – Enigma Blocker (English)

## Name
Enigma Blocker

## Summary
Block ads and trackers locally. YouTube ads, filter lists, whitelist, element picker and stats — no telemetry.

## Description

**Enigma Blocker** is a lightweight ad and tracker blocker with a dark Enigma-style UI.

### Features
- Network blocking via local filter lists
- Cosmetic filtering
- YouTube: skip in-player ads, remove feed ads, collapse empty ad slots
- Per-site whitelist
- Custom filters (EasyList-like syntax)
- Element picker
- Stats & toolbar badge
- Import/export settings

### Privacy
- **No telemetry**
- **All processing is local**
- Bundled filter lists work offline

### Notes
- Some sites may detect blockers.
- Use responsibly and in line with site terms of service.
